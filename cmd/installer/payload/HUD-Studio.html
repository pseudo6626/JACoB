JACoB HUD Studio

SDK14 visual test bench. It exercises themes, alpha, antialiased text, glow, outline, shadow, rounded panels, semantic metrics, progress, brackets, arcs and reticles.

What to look for

Text edges should be smooth with no magenta fringe. Panel translucency should preserve the game underneath. Thin geometry should stay clean at 1080p and above. Glow should read as illumination, not fuzz. Change the sliders while Elite is foreground and compare themes. On Steam Deck, leave this HUD visible and open Game View/Vision: the capture should show Elite without these HUD elements.
