# JACoB 0.2.15-alpha

Hotpatch against the 0.2.14-alpha / SDK 11 distribution.

- Adds persistent manual overrides for the Elite journal folder, the user bindings folder, and one or more shipped ControlSchemes folders. The Settings UI validates paths before saving them. Environment-variable overrides remain supported and take precedence.
- Manual path storage and tests are Unicode-safe, including Cyrillic directory names.
- Keeps the existing international keyboard design: physical controls use layout-independent scan-code tokens, Windows text entry resolves characters through Elite's active keyboard layout and falls back to Unicode input. Adds Cyrillic UTF-16 regression coverage.
- Replaces the short Tutorial with a setup walk-through covering core connection, paths, live journal/state, bindings/input, visual services, LAN, and a bundled Diagnostics custom tab.
- Adds the bundled JACoB Diagnostics tab, installed or refreshed from the Tutorial. It demonstrates the SDK from the same sandbox used by third-party tabs without exporting the scoped Game View media URL.
- Fixes the Windows Graphics Capture privacy border remaining around borderless Elite after Game View stops. The WGC session now closes after about two seconds without capture requests.
- Normal Windows updates no longer run firewall repair, request administrator elevation, or show PowerShell consoles. Network Doctor checks run hidden; firewall elevation occurs only after the user explicitly chooses Repair firewall (admin) and JACoB explains the exact rule being changed.
- Adds Connected devices in Settings. First-time LAN pairing now exchanges the current pair key for a unique per-device credential stored in an HttpOnly SameSite cookie; the server stores only a SHA-256 credential hash. Pair keys rotate on normal JACoB restarts.
- Host-only Remember me persists that device credential for up to 180 days of inactivity. Unremembered devices are session-scoped and removed after disconnect grace. Host-only Admin grants host-reserved JACoB actions to that device, while device trust management remains physically host-only. Devices can be revoked at any time. Pair enrollment is rate-limited per remote address.
- Bumps the custom-tab API to SDK 12 with `Elite.macros`. The Macro Manager is intentionally constrained to quality-of-life use: logistics/menu-navigation built-ins, a 12-step custom limit, no loops or conditionals, recorder-to-macro capture with truncation, a host-accepted responsible-use agreement before edits/custom macros, and host-side serialized execution. Existing SDK 11 namespaces remain compatible.
- Expands persistent diagnostics: rotating `jacob.log` now records process/config/service startup, network/firewall/profile snapshots, WebSocket/device lifecycle, recorder and macro lifecycle, API errors, video-stream lifecycle, and Windows Graphics Capture session creation/rebuild/release without logging credentials, typed text, or journal payloads. `update.log` now rotates and records PID-stamped update stages, service state, actual TCP listener endpoints, Windows network/firewall state, and the no-firewall-mutation policy. LAN-enabled Windows updates verify that the new PID owns a non-loopback listener before declaring success.
