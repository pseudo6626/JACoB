HOW IT WORKS

JACoB stays small on purpose. Your saved HTML tabs provide the controls, automation, displays, and HUDs you want. JACoB supplies the game state, input, journal, video, overlay, and storage interfaces underneath them.

QUICK GUIDE

Tutorial

The shortest path from install to a useful custom tab.

Open full documentation
01

Run Elite, then JACoB

Leave Elite running normally. JACoB watches the current journal and Status.json automatically. Home should show READY or a specific warning that needs attention.

02

Check controls only if needed

If a tab needs a command that is not bound, open Settings → Elite bindings and use Clone / fill unbound while Elite is closed. JACoB creates a separate custom preset instead of editing the source preset.

03

Add a custom tab

Open Tab Manager, paste or upload HTML, preview it, then save. Saved tabs become normal navigation tabs and persist across restarts.

04

Use HUD overlays

Custom tabs can draw text and basic geometry over Elite with the overlay API. Each tab gets its own isolated layer, so several HUD tools can run together.

05

Use another screen

JACoB can be opened from a phone or tablet on the same network. Pair that browser from Settings → LAN access using the displayed token.

06

Build or edit a tab

The Custom Tab Developer Reference contains the complete SDK, message protocol, schemas, overlay scene format, lifecycle rules, and examples in one document.
