HOW IT WORKS

JACoB stays small on purpose. Your saved HTML tabs provide the controls, automation, displays, and HUDs you want. JACoB supplies the game state, input, journal, video, overlay, and storage interfaces underneath them.

COMMUNITY TABS

Community

Find, install, update, remix, and share JACoB tabs without managing package files by hand.

FOR USERS

Install community tools

Browse the official registry, filter by category or capability, and install with one click. JACoB verifies the package size and SHA-256 before saving it.

Browsing and installing do not require a GitHub account.

FOR AUTHORS

Sharing is three steps

  1. Build and test your tab in JACoB.
  2. In Tab Manager, click Share and describe it.
  3. Upload JACoB's generated submission file to GitHub and submit the form.

GitHub sign-in is only required to publish or update a tab. GitHub identifies the maintainer; JACoB never receives the account password or login token.

Macros

Elite macros

Short, linear quality-of-life sequences for interface navigation and logistics. Shipped defaults are restricted to menu/navigation actions. Custom macros are deliberately limited to 12 steps and have no loops or conditionals.

0
Macro use agreement

Frontier's rules prohibit external automation used to generate a player advantage. JACoB macros are intended for accessibility, menu navigation, and repetitive logistical/quality-of-life tasks. Do not use them to automate combat, competitive interactions, unattended gameplay, or other behavior intended to cheat or gain an advantage over other players. You are responsible for compliance with the current Elite Dangerous EULA and Frontier Code of Conduct. The JACoB project does not condone uses that violate those rules or their spirit.
