JACoB Field Guide

Commissioning notes for the bridge, controls, and custom tools.

Open technical library
01

Establish the Elite link

Start Elite, then JACoB. The bridge watches the active journal and Status.json. Bridge should report READY when the host checks are clear.

02

Verify controls when required

If a tool calls an unbound action, close Elite and open Settings → Elite bindings → Clone / fill unbound. JACoB creates a separate custom preset. The source preset is left unchanged.

03

Install a custom tool

Open Tab Manager, load the HTML, inspect Preview, and save it. The tool joins the main navigation and returns after restart.

04

Deploy HUD overlays

Custom tabs can place text and basic geometry over Elite through the HUD interface. Every saved tab receives its own overlay layer.

05

Open a secondary console

A phone or tablet on the same network can open JACoB through a listed LAN address. Pair the browser with the token shown under Settings → LAN access.

06

Build or revise a tool

The Custom Tab Technical Reference records the complete SDK, message protocol, schemas, HUD scene format, lifecycle rules, and working examples.
