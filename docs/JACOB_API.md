# JACoB custom-tab API

The canonical SDK and protocol reference for Alpha 0.2.8 is:

`JACOB_CUSTOM_TAB_REFERENCE.md`

SDK / protocol version: **5**.

The reference covers journal/state events, the `Elite.data` companion-file interface, bounded historical journal access through `Elite.journal.files()` / `Elite.journal.read()`, bindings (including cancelable down/up control), input, recorder access, overlays, video, browser file exports, saved-tab persistence, bounded public API requests, direct WebSocket messages, JSON schemas, lifecycle behavior, security boundaries, and platform capability notes.
